# OC Management Payout Calculator

Standalone browser-based payout calculator for Torn OC management.

## Features
- Unlimited editable income rows
- Three editable payout group names
- Three editable payout percentages
- Default labels:
  - Tier 1 & 2
  - Tier 3 & 4
  - Tier 5 & 6
- Live payout calculations
- Warns if percentages do not total 100%
- Shows unallocated/retained amount
- Saves preferred labels/percentages in browser localStorage
- Copy payout summary button
- No backend required for this version

## Use
Open `index.html` in a browser.

You can also host this as a static page on GitHub Pages, Cloudflare Pages, Netlify, or your own server.
